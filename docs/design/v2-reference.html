      Questions

      What is story order?

      The order events happen inside the fiction. Captain Marvel came out in 2019 but is set in 1995, so in story order it comes before Iron Man. Release order is the order things came out.

      Is Lorestep free?

      Yes. Browsing every watch order needs no account. The tracker and the extension need a free account so your marks can follow you.

      Which streaming services does the extension support?

      Netflix, Prime Video, JioHotstar, HBO Max, Crunchyroll and ZEE5, in Chrome and other Chromium browsers.

      What happens when something has no single right order?

      Watch orders mark branches and side paths, give in-universe dates where the source has them, and flag optional entries, so you can choose.

      Can I make my own order?

      Yes. Lists let you collect titles in any order you like, such as a weekend marathon.
