# Route register

SECURITY-SPEC SEC-03: every client-callable route and the gate it carries. A new route with no row
here fails review. Gates: `none` = public; `session` = Neon Auth session cookie (`requireUser`:
no session = 401, a request carrying `Authorization: Bearer` = 401, Neon Auth unreachable = 503
`auth_unavailable`); `bearer` = Lorestep for Chrome EdDSA JWT verified against Neon Auth's JWKS
(`requireBearerUser`: `iss`, `aud` = `APP_ORIGIN/api/v1/sync`, `client_id`, uuid `sub`; sync
routes only); `csrf` = `assertSameOrigin` (exact Origin, `application/json`, `x-csrf-token` equal
to the `__Host-csrf` cookie). Every session-gated mutation carries `csrf`. No route sends CORS
headers.
