# Route register

SECURITY-SPEC SEC-03: every client-callable route and the gate it carries. A new route with no row
here fails review. Gates: `none` = public; `session` = Better-Auth session cookie; `bearer` = signed
bearer token (`bearer({ requireSignature: true })`); `csrf` = `assertSameOrigin` (exact Origin,
`application/json`, `x-csrf-token` equal to the `__Host-csrf` cookie). No route sends CORS headers.

| Method | Path | Gate | Limiter | Notes |
| --- | --- | --- | --- | --- |
| POST | `/api/prices` | none | none (ITAD concurrency 4) | Existing; spends the ITAD key. |
| GET, POST, PATCH, PUT, DELETE | `/api/auth/*` | Better-Auth (its own origin and CSRF checks) | Better-Auth, `storage: "database"` into `auth_rate_limits`, per IP; stricter `AUTH_RATE_RULES` | Sign-up/in/out, session, password reset (503 `reset_unavailable` without mail), social callbacks, device code/token/approve. |
| GET | `/api/v1/auth-providers` | none | 30/min per IP (`rate_limits`); unresolved IP = 403 | `{ github, google, reset }` booleans. |
| GET | `/api/v1/csrf` | none | none (no DB, no secret) | Sets `__Host-csrf` (HttpOnly, Secure, SameSite=Strict) and returns the same token. |
| GET | `/api/v1/metadata` | session or bearer | 60/min per user (`meta:<userId>`) | `?type&id&title&year`. Fans out to TMDB, OMDb, MAL/Jikan, IGDB; 502 `provider_unavailable` if MAL fails. Per-instance 5 min cache. |
| GET | `/api/v1/search` | session or bearer | 60/min per user (`search:<userId>`) | `?q&type`; at most 30 results; 502 only if every provider failed and nothing was found. |
| POST | `/api/v1/resolve-link` | session (`csrf`) or bearer | 30/min per user (`resolve:<userId>`) | `{url}`. SSRF guard (`guard-url.ts`): https only, no userinfo or port, no IP literal, host on an explicit allowlist, redirects followed by hand and only within the same host, body capped at 1 MB. 422 `unsupported_host` / `unresolvable`. |
| GET | `/api/v1/entries` | session or bearer | none | `?kind&status&q&cursor&limit` (limit clamped 1..100). Owner-scoped, live rows only; keyset cursor on `(updated_at, id)`; a cursor the server did not mint is 400. |
| POST | `/api/v1/entries` | session (`csrf`) or bearer | 120/min per user (`entries:<userId>`) | Body cap 64 KB (413). 201 Entry; 409 `duplicate` (unique game or external id) or `limit` (5000 live entries, checked in the INSERT). |
| GET, PATCH, DELETE | `/api/v1/entries/:id` | session (`csrf` on PATCH/DELETE) or bearer | 120/min per user on PATCH/DELETE (`entries:<userId>`) | Unknown, malformed or foreign id = 404. DELETE is soft (D-16) and, from a cookie caller, still needs `content-type: application/json` and the CSRF header. |
| GET | `/api/v1/lists` | session or bearer | none | The caller's live lists with `itemCount`, newest-updated first (at most 50). |
| POST | `/api/v1/lists` | session (`csrf`) or bearer | 120/min per user (`lists:<userId>`) | `{name<=80, description<=500, kinds}`. Body cap 64 KB (413). 201 List; 409 `duplicate` (same live name) or `limit` (50 lists, checked in the INSERT). |
| GET, PATCH, DELETE | `/api/v1/lists/:id` | session (`csrf` on PATCH/DELETE) or bearer | 120/min per user on PATCH/DELETE (`lists:<userId>`) | GET returns the list with its items in order. Unknown, malformed or foreign id = 404. PATCH 409 `duplicate` on a taken name. DELETE is soft (D-16); items go at purge. |
| POST | `/api/v1/lists/:id/items` | session (`csrf`) or bearer | 120/min per user (`lists:<userId>`) | `{kind,title,year?,extSource?,extId?,imageUrl?}` (source and id together). One INSERT checks owner, live list and the 500-item cap. 201 ListItem; 404 foreign list; 409 `duplicate` (same external id) or `limit`. |
| DELETE | `/api/v1/lists/:id/items/:itemId` | session (`csrf`) or bearer | 120/min per user (`lists:<userId>`) | Unknown, malformed or foreign list or item id = 404. Hard delete of the item row. |
| PUT | `/api/v1/lists/:id/items/order` | session (`csrf`) or bearer | 120/min per user (`lists:<userId>`) | `{ids: uuid[]}` must equal the list's item set exactly: any other set = 400 `invalid_order`; foreign list = 404. One `UPDATE ... FROM unnest`. 204. |
| PUT | `/api/v1/entries/game/:gameId` | session (`csrf`) or bearer | 120/min per user (`entries:<userId>`) | `{status: LibraryStatus\|null, device?, storefront?}`, replaced whole. 404 if the game is not in `games`; 204 when all three are cleared (soft delete). Updating a live row is uncapped; a new row goes through the create insert, so 409 `limit` / `duplicate` as POST. |
| POST | `/api/v1/import/local` | session (`csrf`) | 10/hour per user (`import:<userId>`) | `{entries: Record<gameId,{status,device?,storefront?}>}`, at most 1000 marks and 256 KB. 200 `{inserted,skipped}`; 400 invalid body, 401, 403 (CSRF), 413, 415, 429. Insert-if-absent, server wins. |
| POST | `/api/v1/entries/:id/restore` | session (`csrf`) or bearer | 120/min per user (`entries:<userId>`) | Clears `deleted_at` on the caller's own tombstone within the 30-day purge window; 200 Entry with the same id, links and list memberships. Unknown, malformed, foreign, never-deleted or purged id = 404; 409 `limit` at the live cap, 409 `duplicate` if a live entry took the title. |
| GET | `/library` (page) | session | none | Dynamic, `noindex`. Without a session redirects to `/sign-in?next=/library`; sign-in honours `next` for same-origin paths only. |
| GET | `/account` (page) | session | none | Dynamic, `noindex`. Without a session redirects to `/sign-in?next=/account`. Profile, signed-in devices (read on the server, no token sent), export link, type-the-email erase. |
| GET | `/device` (page) | session | Better-Auth's limiter on `/device`, `/device/approve`, `/device/deny` | Dynamic, `noindex`. Signed out redirects to `/sign-in?next=/device?user_code=…`. No code = a GET form for one. With a code, `GET /api/auth/device` on the server claims it for the caller; Approve/Deny only for a pending Dogear code the caller owns. `/api/auth/device/token` answers a signed `access_token` (after hook, DECISIONS.md) and labels the session "Dogear (Chrome)". |
| GET | `/api/v1/account/export` | session only (bearer = 403 `session_required`) | 10/hour per user (`export:<userId>`) | JSON attachment, `Cache-Control: private, no-store`: profile (no credential columns), entries, entry links, lists, list items, soft-deleted rows included. Never reads `sessions`, `accounts`, `verifications`. |
| DELETE | `/api/v1/account` | session only (`csrf`; bearer = 403) | 10/min per user (`account:<userId>`) | `{confirm}` = the account's email (case-insensitive). One statement deletes every table in `services/account/user-tables.ts`, the user's `rate_limits` and reset `verifications`, then `users`. 204; 400 `invalid_body` / `confirm_mismatch` (nothing deleted). Signs out every device. |
| DELETE | `/api/v1/account/sessions/:id` | session only (`csrf`; bearer = 403) | 10/min per user (`account:<userId>`) | Deletes one of the caller's sessions. Unknown, oversized or foreign id = 404. 204. |
| GET | `/api/cron/purge` | `Authorization: Bearer CRON_SECRET` (sha256 + `timingSafeEqual`; unset secret = 401 for all) | none | Vercel Cron, daily 04:00 UTC (`vercel.json`). Hard-deletes entries and lists soft-deleted over 30 days ago (links and items cascade), expired sessions, verifications and device codes, `rate_limits` and `auth_rate_limits` rows over a day old. 200 `{purged: {per-table counts}}`. |
